# Research PDFs in the document collection

These five papers were selected for the **AI Personalized Trip Planning Assistant** topic. Download the PDFs from the links below and upload them through the app. The source package does not include the PDFs or search indexes.

| Local file | Paper and primary source | Why it helps |
| --- | --- | --- |
| `TravelAgent.pdf` | [TravelAgent: An AI Assistant for Personalized Travel Planning](https://arxiv.org/abs/2409.08069) ([PDF](https://arxiv.org/pdf/2409.08069)) | A direct example of an LLM travel assistant with recommendation, planning, tools, and memory. |
| `ITINERA.pdf` | [ITINERA: Integrating Spatial Optimization with Large Language Models for Open-domain Urban Itinerary Planning](https://aclanthology.org/2024.emnlp-industry.104/) ([PDF](https://aclanthology.org/2024.emnlp-industry.104.pdf)) | Shows how to turn detailed user requests into geographically sensible urban itineraries. |
| `TravelPlanner.pdf` | [TravelPlanner: A Benchmark for Real-World Planning with Language Agents](https://arxiv.org/abs/2402.01622) ([PDF](https://arxiv.org/pdf/2402.01622)) | Gives realistic travel constraints and a benchmark for checking itinerary feasibility. |
| `TripTailor.pdf` | [TripTailor: A Real-World Benchmark for Personalized Travel Planning](https://aclanthology.org/2025.findings-acl.503/) ([PDF](https://aclanthology.org/2025.findings-acl.503.pdf)) | Focuses on user preferences and the quality of personalized travel plans. |
| `TripCraft.pdf` | [TripCraft: A Benchmark for Spatio-Temporally Fine Grained Travel Planning](https://aclanthology.org/2025.acl-long.834/) ([PDF](https://aclanthology.org/2025.acl-long.834.pdf)) | Covers travel time, visit duration, sequencing, and user persona in detailed itineraries. |

The papers are reference material. They are not live sources for prices, schedules, or availability.
