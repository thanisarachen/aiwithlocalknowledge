# AI Personalized Trip Planning Assistant

A browser-based travel planning prototype using a local language model and uploaded travel documents.

## Current demo

The application is in **[trip-planner-github-source](trip-planner-github-source/)**. See its [setup instructions](trip-planner-github-source/README.md) for running the demo with Python and Ollama.

This repository contains source code, not a hosted public website. The root-level `app.py` is an earlier document-Q&A prototype.
